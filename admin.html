Supabase setup
Verbind de poule met je gratis database
⚠️
Nadat je hier opslaat worden de waarden opgeslagen in localStorage van je browser. Kopieer ze daarna ook handmatig naar de CONFIG bovenaan index.html voor productie.
Verbindingsinstellingen
Te vinden in je Supabase project → Settings → API → Project URL
Te vinden in je Supabase project → Settings → API → Project API keys → anon public
Database tabellen aanmaken
Plak dit in Supabase → SQL Editor → New query
-- Tabel 1: Voorspellingen per wedstrijd CREATE TABLE IF NOT EXISTS voorspellingen ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, match_id integer NOT NULL, speler text NOT NULL, score_thuis integer, score_uit integer, pen_winnaar text, created_at timestamptz DEFAULT now(), UNIQUE (match_id, speler) ); -- Tabel 2: Bonusvragen per speler CREATE TABLE IF NOT EXISTS bonus ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, speler text NOT NULL UNIQUE, kampioen text, finalist text, scorer1 text, scorer2 text, scorer3 text ); -- Tabel 3: Handmatige uitslagen (backup) CREATE TABLE IF NOT EXISTS manual_results ( match_id integer PRIMARY KEY, thuis_naam text, uit_naam text, score_thuis integer, score_uit integer, status text, updated_at timestamptz DEFAULT now() ); -- Row Level Security uitschakelen (publiek leesbaar, iedereen kan schrijven) -- Let op: voor een familiepoule is dit prima, niet voor productie-apps ALTER TABLE voorspellingen ENABLE ROW LEVEL SECURITY; ALTER TABLE bonus ENABLE ROW LEVEL SECURITY; ALTER TABLE manual_results ENABLE ROW LEVEL SECURITY; CREATE POLICY "public read" ON voorspellingen FOR SELECT USING (true); CREATE POLICY "public write" ON voorspellingen FOR INSERT WITH CHECK (true); CREATE POLICY "public update" ON voorspellingen FOR UPDATE USING (true); CREATE POLICY "public read" ON bonus FOR SELECT USING (true); CREATE POLICY "public write" ON bonus FOR INSERT WITH CHECK (true); CREATE POLICY "public update" ON bonus FOR UPDATE USING (true); CREATE POLICY "public read" ON manual_results FOR SELECT USING (true); CREATE POLICY "public write" ON manual_results FOR INSERT WITH CHECK (true); CREATE POLICY "public update" ON manual_results FOR UPDATE USING (true);
