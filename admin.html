Supabase setup
Verbind de poule met de database
⚠️ De anon key wordt opgeslagen in localStorage van je browser. Kopieer hem ook naar index.html voor productie-gebruik.
Verbindingsinstellingen
Settings → API → Project URL
Settings → API → Project API keys → anon public (ook wel "Publishable key")
SQL tabellen aanmaken
Plak dit in Supabase → SQL Editor → New query → Run
CREATE TABLE IF NOT EXISTS voorspellingen ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, match_id integer NOT NULL, speler text NOT NULL, score_thuis integer, score_uit integer, pen_winnaar text, UNIQUE (match_id, speler) ); CREATE TABLE IF NOT EXISTS bonus ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, speler text NOT NULL UNIQUE, kampioen text, finalist text, scorer1 text, scorer2 text, scorer3 text ); ALTER TABLE voorspellingen ENABLE ROW LEVEL SECURITY; ALTER TABLE bonus ENABLE ROW LEVEL SECURITY; CREATE POLICY "open" ON voorspellingen FOR ALL USING (true) WITH CHECK (true); CREATE POLICY "open" ON bonus FOR ALL USING (true) WITH CHECK (true);
